# vnznznznz.github.io

Web pages for Night Courier, served by GitHub Pages:

- `night-courier/` – help and contact (also the App Store Support URL and Google Play's account
  deletion page)
- `night-courier/privacy-policy.de.html` – privacy policy (German, binding)
- `night-courier/privacy-policy.en.html` – privacy policy (English translation)

The pages are built from `docs/store/` in the Night Courier app repository, where the operator's
details are placeholders; they are filled in only here. Change the text there, then rebuild.
`.nojekyll` makes GitHub serve the files as they are, with no theme and nothing loaded from
elsewhere.
